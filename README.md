# Multi Flow

Instaladores y actualizaciones de **Multi Flow**: herramientas que hacen el trabajo
entero dentro de tu equipo (editor de PDF, conversor Word ↔ PDF, transcriptor,
subtítulos, imágenes y limpieza de metadatos). Sin cuentas, sin suscripciones y sin
subir tus archivos a ningún lado.

## Instalar

Descarga `MultiFlow-Setup-<versión>.exe` desde [Releases](../../releases/latest) y
ábrelo. Windows puede avisar con SmartScreen porque el instalador no está firmado:
«Más información» → «Ejecutar de todas formas».

## Actualizaciones

La aplicación instalada busca versiones nuevas al abrirse y cada 6 horas. Si hay una,
la descarga en segundo plano y la instala al cerrar Multi Flow (o al pulsar
«Reiniciar y actualizar» en el inicio). La versión portátil no se actualiza sola.

Este repositorio sólo contiene los instaladores; el código no se publica.
